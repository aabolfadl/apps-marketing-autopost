How to run a trivia night with one phone.

1. Name the teams. Real names beat Team 1 and Team 2.
2. Set your own rules. How many questions per difficulty, how many points each is worth.
3. Pick topics that suit the room.
4. Pass the phone. Whoever holds it reads the question out.
5. Type what the team actually said. The app rules on it and shows the accepted answers.
6. The final standings settle the argument.

Host tip: turn on Keep screen awake in Settings first, so the phone does not lock halfway through a question.
